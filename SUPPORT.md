# Support

CYUNEO Agent Monitor is a one-person, source-available project. Support happens in public on GitHub.

## Where to ask

- **Bugs, questions and ideas:** [GitHub Issues](https://github.com/cyuneo/cyuneo-agent-monitor/issues). Please search the existing issues first.
- **Security problems:** don't open a public issue. Follow [SECURITY.md](SECURITY.md) instead.

There is no support email.

## What to include in a bug report

- The versions of VS Code, CYUNEO Agent Monitor, and Claude Code and/or Codex you use.
- Your operating system.
- Where you use Claude Code or Codex: the VS Code extension, the terminal or the desktop app.
- What you expected to see, and what you saw instead. A screenshot helps.
- Any error messages. They appear in **View → Output**, under **Agent Monitor** in the drop-down list.

## Keep your conversations private

Session records contain your prompts, code and file paths. **Please don't attach session record files (`.jsonl`) or paste conversation text into an issue.** If a record seems to cause the problem, describe its structure instead (for example, which line types appear), or remove the content first.

## Response times

Issues are handled on a best-effort basis. There is no guaranteed response time.
