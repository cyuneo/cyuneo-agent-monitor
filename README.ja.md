## なぜ作ったのか

Claude CodeとCodexは今や、複数のエージェントを同時に動かします。サブエージェント、バックグラウンドエージェント、ワークフロー全体まで。ところがVS Codeでは、その作業のほとんどが見えません。

- **誰が何をしているか見えない。** エージェントビューは自分で開かないと表示されないため、承認待ちのエージェントが誰にも気づかれずに止まっていることがあります。
- **コンテキストが静かに埋まっていく。** 自動圧縮が都合の悪いタイミングで始まったり、長い会話が内容を忘れ始めたりして、ようやく気づきます。
- **少し離れるとキャッシュが切れる。** 1時間後に戻ると、次のメッセージでコンテキスト全体を通常料金で読み直すことになります。
- **使用量の上限で作業が途中で止まる。** エージェントが止まったら、自分で気づき、リセットを待ち、手動で再開させなければなりません。

## できること

- **すべてのチャットをひと目で。** ターミナルの隣のパネルに、開いているチャットと最近のチャットがステータスランプ付きで並びます。クリックすると、その中のエージェント、それぞれが進めている手順、トークン数と費用がわかります。
- **自分の出番がすぐわかる。** 承認や回答を待っているチャットはマゼンタのランプで知らせます。完了やエラーもそれぞれの色で表示され、ステータスバーにも出ます。
- **席を離れていても知らせてくれる。** チャットが対応を待ち始めると、VS Codeやシステムの通知でお知らせします。必要なら、スマートフォンやチームのチャット（ntfy、Bark、ServerChan、Feishu、DingTalk、WeCom、Telegram、Discord、Slack）に短いメッセージを送ることもでき、エラーや使用量の上限も知らせます。
- **コンテキストを管理できる。** 各チャットのコンテキストの埋まり具合を確認し、パネルから直接圧縮し（安いモデルも選べ、先に費用の見積もりを確認できます）、自動圧縮のタイミングを自分で決め、キャッシュが切れる前に通知を受けられます。
- **使用量の上限のあとも続けられる。** 上限がいつリセットされるかを表示し、再開用のプロンプトやコマンドを用意するので、コピーするだけで使えます。
- **チャット記録の保存場所がわかる。** 使っている容量を表示し、別のディスクへ移すための参考コマンドも示します。

Claude CodeとCodexがすでにコンピューター上に書き込んでいる記録を読み取るだけで、データも収集しません。プッシュ通知（既定はオフ）をオンにするか自分でテストメッセージを送らない限り、拡張機能自体はネットワークに接続しません。

## 使い始める

1. 上の**VS Codeにインストール**をクリックするか、拡張機能ビューで**CYUNEO Agent Monitor**を検索します。
2. 下部パネルでTerminalの隣にある**エージェントモニター**タブを開きます。
3. 一覧のチャットをクリックすると、そのチャットのエージェントが表示されます。

すべての機能、コマンド、設定の詳しい説明は**[完全ガイド](docs/GUIDE.ja.md)**をご覧ください。

## 必要環境

- VS Code 1.94以降。
- 同じコンピューター上のClaude CodeおよびCodex（VS Code拡張機能、コマンドライン、またはデスクトップアプリ）のいずれか、または両方。
- 閉じたチャットをバックグラウンドで圧縮するには、Claude Codeのコマンドラインも必要です。拡張機能はPATH上の`claude`をまず探し、次にインストール済みのClaude Code拡張機能内を探します。`agentMonitor.claude.cliPath`を設定することもできます。
- macOSでテスト済みです。WindowsとLinuxはまだテストされていません。

## プライバシー

- テレメトリはなく、プッシュ通知をオンにするか自分でテストメッセージを送らない限りネットワークにも接続しません。会話の内容はお使いのコンピューターから出ません。
- プッシュ通知はオプションで、既定はオフです。オンにすると、設定したサービスに短いメッセージだけを送ります。内容はプロジェクトフォルダー名と状態で、許可した場合はチャットのタイトルとサブエージェント名も加わります。それ以外がコンピューターの外に出ることはありません。
- ファイルを変更したりClaude Codeを実行したりするのは、ご自身が確認した後だけです（[免責事項](#免責事項)を参照）。
- 詳しくはガイドの[読み取る内容](docs/GUIDE.ja.md#読み取る内容)と[プライバシー](docs/GUIDE.ja.md#プライバシー)をご覧ください。
